# Multi-Period Models API

Multi-period model classes, in `src/potpourri/models_multi_period/`.

These mirror the single-period stack with every variable and
constraint additionally indexed over a time set. Flexible devices
attach to a built multi-period model; see
[Flexible Devices](devices.md).
